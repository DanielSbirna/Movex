Shipping Shouldn't Be Complicated

Traditional shipping often means dealing with fragmented pricing, long lines, rigid pickup hours, and zero visibility once your package is on the move.

Whether you are sending a gift, returning an item, or managing high-volume business shipments, the old way is slow, inconvenient, and difficult to track.

A Smarter Way to Ship

Movex simplifies logistics from start to finish. Create shipments online, calculate costs instantly, track packages in real time, and utilize smart lockers for flexible pickup and drop-off.

Backed by a connected network of couriers and automated lockers, sending a package becomes fast, transparent, and entirely seamless.

Core Features
Feature

Send a Package

Allows users to schedule a courier pickup or drop off items at any of our locker locations.

Requirements:

  • User must be authenticated;
  • User must complete the standard shipment request form.
Feature

Calculate Cost

Provides an instant shipping estimate, allowing users to quickly compare rates with other delivery options.

Requirements:

  • User must input package specifications (dimensions and weight);
  • User must specify origin and destination locations.
Feature

Track a Package

Provides real-time status updates using a unique tracking code.

Requirements:

  • User must enter a valid AWB code.
Feature

Find a Locker

Helps users locate locker terminals on an interactive map within our operational service area.

Feature

Bulk Shipping

Enables users to arrange specialized vehicles and equipment required for high weight volume shipments or heavy freight.

Note:

  • Bulk shipments are restricted to scheduled courier pickup and delivery services only.
